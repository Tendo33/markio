# Design-MD Workflow

This repository does not currently have a root `DESIGN.md`.

For small console maintenance, follow the existing Vue console implementation and `frontend/src/style.css`.

For substantial UI redesign:

1. Create or update root `DESIGN.md` first.
2. Use design-md/getdesign style references to define the intended visual direction.
3. Capture layout density, color, typography, component states, data tables/cards, forms, and error states.
4. Implement after the design source exists.

Do not invent a new visual language inside `.trellis/spec` alone.
